# Mentor card

One row of `/mentors` (spec #27): who the mentor is, what they have done, their prices and next open time. Built only with Tailwind and tokens, exported from `@devmentor/ui/mentors` (public pages never import shadcn, AGENTS.md, spec #27).

## When not to use
- On signed-in lists that need row actions or a professional headline (favorites): compose a row from its classes until the card gets an actions slot ("What is missing").
- For the mentor's own page or preview: **Mentor page view**.
- In admin tables: **Table / DataTable**.
- Without a bookable offer: the list only shows offer-ready mentors (spec #27); never render a card with empty prices.

## Rules
| Rule | Source |
|---|---|
| A list row with a thin line under it, not a floating card | R01.1, R03.2 |
| Name links to `/m/<slug>`; public-work link opens a new tab with `rel="noopener nofollow ugc"`, text = host + path cut at 60 | spec #27, #28 |
| Bio cut at 280 characters on the server and clamped to 3 lines | spec #27 |
| Prices as separate fact chips, mono with tabular figures | R03.3, R03.1 |
| "Next open time:" via `LocalTime` (viewer's zone, UTC before hydration) | spec #22, #27 |
| No rating, score, rank, "top", "popular" or session count | N02, A02 |
| Say "open times", never "available now" or "guaranteed" | spec #27 |
| Avatar: GitHub photo or initial on `--muted` | A01, POSTEP Q4 |

## Data states
| State | Story |
