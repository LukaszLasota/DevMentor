# Tag filter

The `/mentors` filter (spec #27): a `nav` (`aria-label="Filter by stack tag"`) of links — All, TypeScript, React, Python, AI agents — one value at a time via `?tag=<key>`.

| Rule | Source |
|---|---|
| Links, not a select or chips with checkboxes; no text input, no sort control | spec #27, R08 |
| Active link: `aria-current="page"`, muted fill and underline (not colour alone) | WCAG 1.4.1 |
| Targets at least 32 px high | WCAG 2.5.8 |
