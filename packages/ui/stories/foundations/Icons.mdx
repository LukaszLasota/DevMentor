# Icons

| Rule | Source |
|---|---|
| One icon set for the whole product: Lucide (already the shadcn base set, `lucide-react`) | lesson 06 (one set, never two) |
| Icons sit in a 20 px box inside buttons; stroke width matches the text weight | trainer (button); stroke approved 2026-10-22 |
| An icon-only button always has an accessible name (`aria-label`) | WCAG 4.1.2 |
| An icon next to a status is paired with text; colour or icon alone never carries meaning | WCAG 1.4.1 |
| Emoji are not icons; no sparkles as a symbol for AI | R02.4 dislike, A01 |
| No icons on coloured tiles next to headings | A01 |

Open: Lucide is part of the default shadcn look (lesson 06). Keeping it was approved 2026-10-22; switching sets would be a separate decision.
