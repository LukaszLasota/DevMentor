# Themes

Light and dark use the same token names; only the values change. Switch with the **Theme** control in the toolbar: it sets the `dark` class on `<html>`, so dialogs, menus and popovers rendered outside the story follow the theme (prompt rule 9).

| Rule | Source |
|---|---|
| Every colour role has a light and a dark value; contrast is checked in both (Foundations/Color) | lesson 06 |
| The action colour is lighter in dark mode (the light value would be 3.7 : 1 on the dark background) | trainer; dark value approved 2026-10-22 |
| Story tests run in both themes: `npm run test:storybook -w @devmentor/ui` | lesson 06, stage 1 |
