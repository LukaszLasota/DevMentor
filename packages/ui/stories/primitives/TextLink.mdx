# Text link

## 1. Purpose
Takes the user to another page or site from running text.

## 2. When to use
- "Find a mentor" on the home page (spec #27), switching between `/sign-in` and `/register` (spec #21).
- A mentor's public work link on `/m/[slug]` (`external`, R04).

## 3. When not to use
- For an action that changes data: use **Button**.
- For the main call to action of a page: use a `Button` with `asChild` around the router link.

## 4. Anatomy
Underlined text · optional external icon with "(opens in a new tab)" for screen readers.

## 5. Variants
| Variant | Choose when |
|---|---|
| internal (default) | Pages inside DevMentor |
| `external` | Other sites; opens a new tab and says so |

## 6. States
<Canvas of={Stories.StateMatrix} />

Hover thickens the underline; focus shows the 2 px `--ring` outline. Links have no disabled state: hide or replace a link that leads nowhere.

## 7. Behaviour and accessibility
- Always underlined, so colour is not the only cue (WCAG 1.4.1). Contrast `--link` on background 4.9 : 1 light, 7.0 : 1 dark.
- Enter follows the link. External links get `rel="noopener noreferrer"`.
- Inline links in a sentence are exempt from the 24 px target rule (WCAG 2.5.8).

## 8. Content
Describe the destination, not "click here": "Browse mentors by stack tag". Keep it under about eight words.

## 9. Responsive
