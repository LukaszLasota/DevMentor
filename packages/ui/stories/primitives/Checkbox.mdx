# Checkbox

## 1. Purpose
Turns one option on or off, or picks several options from a short list.

## 2. When to use
Stack tags on the mentor profile: TypeScript, React, Python, AI agents (spec #23).

## 3. When not to use
- One choice out of several: radio group (not in the system yet, see "What is missing").
- An instant on/off setting: switch (not in the system yet).

## 4. Anatomy
16 px box with a 4 px radius (stage 2 Q3) · check mark · label to the right, inside a **Field** with `inline`.

## 5. Variants
One look; groups use `<fieldset>` with a `<legend>`.

## 7. Behaviour and accessibility
- Space toggles; clicking the label toggles too.
- The box is 16 px, but the label row is at least 24 px high and clickable, so the target passes WCAG 2.5.8.
- Checked uses `--primary` with a check mark, so state is not shown by colour alone.

## 8. Content
Labels are the option names as written in the vocabulary ("AI agents").

|---|---|
