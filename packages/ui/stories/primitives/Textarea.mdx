# Textarea

## 1. Purpose
Lets the user write several lines.

## 2. When to use
A mentor's bio (spec #23): what they have done, in plain words (R04).

## 3. When not to use
- One line: **Input**.
- Messages during a session: the session composer is a product component (stage 3, R02.1).

## 4. Anatomy
Outline · text · grows with content (`field-sizing-content`), minimum 96 px.

## 5. Variants
One look.

## 6. States
<Canvas of={Stories.StateMatrix} />

## 7. Behaviour and accessibility
Same outline, focus and disabled rules as **Input**. Enter adds a new line; it never submits a form.

## 8. Content
Say how long the text may be in the hint, and give the current count in the error.
