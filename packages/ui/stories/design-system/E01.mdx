# E01 Mentor onboarding

An invited senior engineer becomes a bookable mentor: sign in, accept the invitation, fill the page, publish, set prices, publish open times (payouts in 1.1).

## Flow
1. `/invitation/[token]` — sign in with GitHub (or email), accept the invitation (spec #22).
2. `/mentor` — checklist with the publish-by date: page, prices, slots, payouts link.
3. `/mentor/profile` — form, readiness, Publish; then share link and Unpublish (spec #23).
4. `/mentor/prices` — two prices within the operator bounds (spec #24, blocked on currency).
5. `/mentor/slots` — publish start times; lead-time state; remove (spec #25).
6. `/mentor/payouts` — Stripe Connect (spec #26, 1.1).
