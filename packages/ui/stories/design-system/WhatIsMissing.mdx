# What is missing

## Components not in the system
| Missing | Why it is not built | Use for now |
|---|---|---|
| Radio group | No E01/E02 screen needs it | Links (filter) or Select |
| Switch | Same | Checkbox ("Show past") |
| Popover, Tooltip | Same; needed info is never hidden | Visible text |
| Tabs | Same | Separate pages |
| Toast | Errors that need action never use it; success is inline | Alert |
| Side panel | Not needed | Dialog or page |
| App shell (header, navigation, sign-out) | No spec defines it; screen stories use proposal frames | — |
| `CrudForm` `datetime` field (zone note, resolved-time echo, DST gap error) | Built with spec #25 | — |
| Session view (conversation, composer, author + time per message) | E04, not in E01/E02 | R02.1–R02.3 recorded |
| `MentorCard` slot for row actions and a professional headline | Found by the agent test (favorites); no `headline` field in the data model or specs | Compose a row from MentorCard's classes; add the slot with the first real screen |
| Favorites (mentee) | Not in the E01/E02 backlog; designed only as the agent test | Rules in docs/design-system.md → Lists and row actions |
